Connect

Publishing writes directly to your GitHub repo through the GitHub API — no server in between. Use a fine-grained personal access token scoped to just this one repository, with Contents: Read and write permission and a short expiry. Create one at github.com/settings/personal-access-tokens/new. This page is public like the rest of the site — it's harmless to anyone without your token, since nothing writes without one.

Publish a guide

A subject is a folder — assets/guides/year-{n}/sem-{n}/{subject-slug}/, created automatically the moment its first file lands in it. What you're publishing each time is one item inside that folder: a numbered week, or a freeform "special" entry like a Midterm Reviewer. Republishing the same Year/Semester/Code/item only touches that one item — every other week or special entry already in the subject is left alone.

Works well for typical guide sizes. The GitHub Contents API this page uses caps out around 1 MB per file — for anything larger, push it with git normally instead.

To add or replace just the PDF on an item you already published, leave the HTML paste box empty (or don't choose an HTML file), keep the same Year/Semester/Code/item, attach the PDF, and publish — the existing HTML is left untouched. Same the other way around for an HTML-only update.

Publish a reference

For material that isn't tied to a specific Year/Semester/Subject — a full HTML/CSS reference, a GitHub mastery guide, anything meant to be useful across the whole curriculum. Grouped by a category you name yourself (reuse the same category on a later publish to add another item under it); lives at assets/references/{category-slug}/{item-slug}/, separate from the year-by-year guides. Shows up in the sidebar under its own "Reference Library" section.

To add or replace just the PDF on a reference you already published, leave the HTML paste box empty (or don't choose an HTML file), keep the same Category/Title, attach the PDF, and publish — the existing HTML is left untouched. Same the other way around for an HTML-only update.
