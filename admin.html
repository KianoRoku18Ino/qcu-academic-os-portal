Connect

Publishing writes directly to your GitHub repo through the GitHub API — no server in between. Use a fine-grained personal access token scoped to just this one repository, with Contents: Read and write permission and a short expiry. Create one at github.com/settings/personal-access-tokens/new. This page is public like the rest of the site — it's harmless to anyone without your token, since nothing writes without one.

Publish a guide

Folders aren't separate objects in git — one just appears the moment the first file lands in it. Pick Year + Semester + Subject below and publishing creates assets/guides/year-{n}/sem-{n}/{subject-slug}/ automatically if it doesn't exist yet, or updates the file in place if it does.

Works well for typical guide sizes. The GitHub Contents API this page uses caps out around 1 MB per file — for anything larger, push it with git normally instead.

To add or replace just the PDF on a guide you already published, leave the HTML paste box empty (or don't choose an HTML file), keep the same Year/Semester/Code, attach the PDF, and publish — the existing HTML is left untouched. Same the other way around for an HTML-only update.
