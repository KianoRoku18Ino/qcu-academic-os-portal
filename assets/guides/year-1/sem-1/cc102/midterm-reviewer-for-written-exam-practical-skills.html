CHAPTER 01
Logic Formulation & Flowcharts (Weeks 2-3)

Before writing code you must be able to describe the solution as clear, finite steps. Flowcharts and pseudocode are the two tools the exam checks.

i
Local analogy

An algorithm is like a recipe for adobo: exact steps, a finite number of them, and a dish at the end (the output). A flowchart is the jeepney route map of that recipe. The oval is the terminal (start or end of the route). The diamond is the LRT turnstile: tap your card - valid? Yes, the gate opens; No, it stays shut. One way in, two ways out.

×
Why E loops forever

x never changes, so x < 10 is always true. Every loop needs an update step that moves the variable toward making the condition false.

Common Mistakes

Decision with one exit
A diamond always has two labeled exits (TRUE/FALSE or Yes/No). Unlabeled exits lose points.
Start/End arrows
Start has no entrance; End has no exit. Do not draw an arrow into START.
Hexagon vs rectangle
Hexagon = declare/initialize (age = 19). Rectangle = compute or assign (futureAge = age + 5).
Forgetting the loop update
A loop arrow that returns to the decision without changing the variable is an infinite loop.

Common Mistakes

File/class mismatch
Public class HelloJava inside hello.java gives: class HelloJava is public, should be declared in a file named HelloJava.java.
Wrong casing
system.out.println (lowercase s) fails. Java is case-sensitive: System, String, Scanner start with capitals.
Mangled main
Missing static, wrong return type, or String args without brackets will not run as the entry point.
Missing semicolon
Every statement ends with ; - the compiler error is "';' expected".

Local, Instance and Static Variables

VariableTypes.java
public class VariableTypes {
    int instanceNumber = 50;          // INSTANCE: inside class, outside any method
    static int staticNumber = 100;    // STATIC: shared by every object

    public void displayVariables() {
        int localNumber = 90;         // LOCAL: inside a method body
        System.out.println("Instance Variable: " + instanceNumber);
        System.out.println("Static Variable: " + staticNumber);
        System.out.println("Local Variable: " + localNumber);
    }

    public static void main(String[] args) {
        VariableTypes obj = new VariableTypes();   // creates one object
        obj.displayVariables();
    }
}
output
Instance Variable: 50
Static Variable: 100
Local Variable: 90

LocalInside a method or constructorOnly that methodUntil the method ends
InstanceInside the class, outside methodsEach object has its own copyAs long as the object exists
StaticInside the class with the static keywordShared by all objectsWhole program run

float without f

long literal

Instance from static

CHAPTER 04
Java Operators (Week 6)

The highest-yield exam chapter: tracing expressions exactly as Java evaluates them.

i
Local analogy

Think of a sari-sari store counter. Arithmetic is computing the total of the items. Relational operators compare (is this brand cheaper than that one?). Logical operators combine requirements, like a scholarship that needs "GWA of 1.75 or better AND no failing grade". For ++: ++x is topping up your GCash and then checking the balance; x++ is checking the balance first and the top-up lands afterwards.

Expression = variables + literals + operators that produce a result. It is used to compute values, assign values, and control program flow. An operator is the symbol; an operand is the value it works on (in a + b, + is the operator, a and b are operands).

Clarification

The pasted reviewer listed prefix ++/-- above postfix. In Java, postfix binds tighter. It rarely changes an exam answer, but if a question asks which is higher, answer postfix. If your instructor's slide says otherwise, follow the slide for that item.

String Concatenation Is Left to Right

trace
int a = 10, b = 3;
System.out.println("Sum = " + a + b);        // Sum = 103   ("Sum = 10" then + 3 as text)
System.out.println("Sum = " + (a + b));      // Sum = 13    (parentheses add first)
System.out.println("Result = " + a + b * 2); // Result = 106 (b*2 = 6 first, then text joins)
System.out.println("Result = " + (a + b * 2)); // Result = 16

Lab: OperatorDebug

original (as given)
int a = 10;
int b = 3;
System.out.println("Sum = " + a + b);          // wrong result: Sum = 103
System.out.println("Product = " + (a * b));    // OK  -> 30
System.out.println("Equal = " + (a = b));      // compiles! assigns a = 3, prints Equal = 3
System.out.println("Greater = " + (a > b);     // compile error: missing )
System.out.println("Result = " + a + b * 2;    // compile error: missing )
corrected
System.out.println("Sum = " + (a + b));        // 13
System.out.println("Product = " + (a * b));    // 30
System.out.println("Equal = " + (a == b));     // false
System.out.println("Greater = " + (a > b));    // true
System.out.println("Result = " + (a + b * 2)); // 16
!
Why (a = b) is the sneaky one

It is valid Java: an assignment produces the assigned value (3) and, worse, changes a to 3, so every later line uses the wrong a. The compiler only complains about the two missing parentheses. Explain all three problems when asked "why was the code incorrect".

25 Rapid-Fire Facts

  1. Program cycle: problem definition, problem analysis, algorithm development, coding and debugging.
  2. An algorithm needs exact steps, a finite number of steps, and an output.
  3. Decision = diamond; I/O = parallelogram; process = rectangle; terminal = oval; initialization = hexagon.
  4. Java: created 1991 by James Gosling and team at Sun Microsystems; names Greentalk, Oak, then Java.
  5. Java is platform independent because bytecode runs on the JVM.
  6. Entry point: public static void main(String[] args).
  7. byte range is -128 to 127; short is 16-bit; int is 32-bit; long is 64-bit.
  8. double is the default type for decimal literals; float needs f; long needs L for large literals.
  9. char uses single quotes; String is non-primitive and uses double quotes.
  10. = assigns; == compares.
  11. && needs both true; || needs at least one true; ^ is true when inputs differ; ! reverses.
  12. ++x changes first then uses; x++ uses first then changes.
  13. Precedence: ( ) then * / % then + - then relational then == != then && then ||.
  14. int / int drops the decimal; % gives the remainder.
  15. The condition of if or while must be boolean.
  16. In your lessons switch uses int or char; each case ends with break; default is the fallback.
  17. break leaves a loop or switch; continue skips the current iteration; return leaves a method.
  18. while is pre-test; do-while is post-test and runs at least once.
  19. An infinite loop usually means a missing update statement.
  20. Scanner methods: nextInt(), nextDouble(), next(), nextLine().
  21. print has no newline; println adds one; printf formats.
  22. 10 + 5 * 2 = 20 and (10 + 5) * 2 = 30.
  23. 7 - 24 / 8 * 4 + 6 = 1.
  24. File name must match the public class name.
  25. Local variables live in a method; instance variables belong to each object; static variables are shared.
