CHAPTER 00
Course Overview & Study Priority Map

WS101 (Web Systems and Technologies 1) teaches how the web works and the three front-end languages: HTML for structure, CSS for presentation, and JavaScript for behavior. The lectures move from vocabulary, to markup, to styling, to programming logic, and the two activities force you to combine all three.

🎯

Static vs Dynamic Web Pages

FIGURE 1
Static Web Page

One round trip. The browser sends an HTTP request, the server returns the ready-made HTTP response. Same content for everyone until the file is edited.

FIGURE 2
Dynamic Web Page

The server runs a program first, so content can vary per request (user, time, database). Four steps, listed below.

1
Step 1: HTTP request
The browser asks the web server for a page.
2
Step 2: Server calls an application program
The server invokes a program in response to the request.
3
Step 3: Program executes and produces HTML output
The program builds the HTML result.
4
Step 4: HTTP response
The server sends the generated HTML back to the browser.

iframe

<iframe> is not tied to <frameset>. It can appear anywhere in a document and defines a rectangular region that displays a separate document, including scrollbars and borders. It shares the attributes src, name, frameborder, marginwidth, marginheight, noresize. (The slide writes <iframeset> by mistake.)

⚠️
Frames are obsolete

HTML5 removed <frameset>/<frame>. <iframe> still works and is used for embedded maps and videos.

What is CSS?

Cascading Style Sheets. A simple mechanism for adding style to web documents. It describes how HTML elements are displayed on screen, paper, or other media.

css

  font-size: 13px;
}

CSS1
Co-creator

Three Types of CSS

html
<!-- 1. Inline CSS: style attribute on one element -->
<h3 style="color:green; font-style:italic;">Inline</h3>

<!-- 2. Internal / Embedded CSS: <style> in the head -->
<head>
  <style>
    h3 { font-family: Arial; font-style: italic; color: green; }
  </style>
</head>

<!-- 3. External CSS: separate .css file linked in the head -->
<head>
  <link rel="stylesheet" href="styles.css">
</head>
💡
Which wins?

Inline styles override internal and external styles. External CSS is best for consistency across many pages, which is exactly what the "consistency of look and feel" characteristic refers to.

Anatomy of a JavaScript Program

🚫
JavaScript is not Java

JavaScript does not need a class, a public modifier, or a main() method. There is no public class Main and no public static void main(String[] args). A JavaScript program is just a list of statements that runs top to bottom, either inside <script></script> tags or in a plain .js file. This mix-up usually happens because CC102 is taught in Java at the same time.

java
// Java: needs a class and a main method before anything runs
public class Main {
  public static void main(String[] args) {
    System.out.println("Hello World");
  }
}
javascript
// JavaScript: no class, no main() -- statements just run, top to bottom
alert("Hello World");
document.write("Hello World");
console.log("Hello World");
