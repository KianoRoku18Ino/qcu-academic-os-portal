CHAPTER 01
IT Industries & Profession

Before diving into hardware and theory, CC 101 opens with the bigger picture: what does a career in IT actually look like? This chapter distinguishes a job from a profession, maps the major categories of IT careers, and surveys where computers show up across every industry — the same framing QCU uses in Week 2 of the course.

Job vs. Profession

A recurring exam-style question in this topic is simply: what is the difference between a job and a profession?

NARROWER CONCEPT
Job
A much narrower concept than a profession. A profession creates the place for a job — in other words, the profession comes first, and jobs exist within it.
BROADER CONCEPT
Profession
Indicates a broad field. A profession is something we have studied for — it requires educational qualifications as well as training, unlike a job, which doesn't necessarily require either.

The Four Categories of IT Careers

Every IT career opportunity falls under one of four broad categories, grouped by the main focus of the job.

Technical writing: turning engineers' technical skills and knowledge into written documentation.

CATEGORY 2

Software development: creation of new software products for commercial sale.
Systems programming: highly specialized work writing instructions in C++, JavaScript, or other languages to accomplish a succession of tasks.
Multimedia development: using computers to create images, sounds, and movies.
Quality assurance (QA): testing new products before they're released to the public.

CATEGORY 3
Application Development Careers

Application development: uses commercial software to build a system for a specific organization.
Systems analysis: gathering requirements and developing a design for systems.
Database administration: particularly important since the database sits at the core of a company's information systems.
Network administration: operations and maintenance of a company network.
Web administration: keeping a website working and up-to-date.

CATEGORY 4
Hardware Design Careers

Hardware design: the specification of computer hardware such as CPUs, video cards, and memory chips. Many hardware designers are electrical engineers, and many are computer engineers.

CHAPTER 02
History, Generations & Types of Computers

Computers evolved over thousands of years from simple counting tools to quantum processors. This chapter traces that full evolution — the inventors, machines, and technological leaps that define each generation — then covers the different types of computers in use today. Expect exam questions on key names, dates, what defined each generation, and how each computer type differs.

Pre-Computer Era: Ancient Tools

~3000 BC
Abacus — Mesopotamia & China
Earliest known computing device. Beads on rods represent number columns. Used for arithmetic. Still used in some Asian schools for mental math training. Remarkably fast in trained hands.
~150 BC
Antikythera Mechanism — Ancient Greece
Recovered from a Greek shipwreck. A bronze-geared analog device used to predict astronomical positions and eclipses. Often called the world's first analog computer. Its complexity wasn't matched for over 1,400 years.
1450
Movable-Type Printing Press — Johann Gutenberg, Germany
Marks the start of the "Mechanical Age of Computing" (1450–1840) in QCU's official lecture sequence. Gutenberg's movable metal-type printing process triggered the first information explosion in history, making the mass production and spread of written knowledge possible for the first time.
1617
Napier's Bones — John Napier, Scotland
Numbered rods used to simplify multiplication and division. Napier also invented logarithms, which revolutionized scientific calculation. The rods were engraved with multiplication tables cut into sections to allow rapid multiplication.
1642
Pascaline — Blaise Pascal, France
Age 19 when he built it
First true mechanical calculator, built to help his father with tax computations. Could add and subtract using interlocking gears. About 50 were built. Pascal is also the namesake of the Pascal programming language.
1673
Stepped Reckoner — Gottfried Leibniz, Germany
Improved on Pascal's machine to also perform multiplication and division. Leibniz also advocated for the binary number system — the same system all modern computers use today.
1804
Jacquard's Loom — Joseph Marie Jacquard, France
Simplified the manufacturing of textiles with complex patterns (brocade, damask, matelassé) using punched cards with punched holes — each row of holes corresponding to one row of the fabric design. Its punch-card control system directly inspired the input method Babbage later used for the Analytical Engine.
1822
Difference Engine — Charles Babbage, England
Designed (never fully completed during his lifetime) to compute mathematical tables automatically, eliminating human calculation errors. This machine is what earns Babbage the title "Father of the Computer."
1837
Analytical Engine — Charles Babbage & Ada Lovelace
Babbage's more ambitious design: a general-purpose mechanical computer with separate memory ("store") and processor ("mill"), capable of conditional branching and loops. Ada Lovelace wrote notes on this machine including what is recognized as the first algorithm intended for a machine — making her the world's first programmer.
1854
Boolean Algebra — George Boole, England
Boole published "An Investigation of the Laws of Thought," establishing Boolean algebra: a system of logic using only TRUE and FALSE (1 and 0). This mathematical foundation is what makes all digital computing possible — every computer operation reduces to Boolean logic.
1890
Punch Card Tabulator — Herman Hollerith, USA
Built for the 1890 US Census. Used electrical sensing to tabulate data on punched cards — cutting census processing from an estimated 8 years to just 18 months. Hollerith founded the Tabulating Machine Company, which eventually became IBM.
1936
Turing Machine — Alan Turing, England
Not a physical machine but a theoretical model: a device that reads/writes symbols on an infinite tape according to a set of rules. Turing proved this simple machine could compute anything computable — laying the theoretical foundation of all computer science. Turing also broke the Nazi Enigma code in WWII, shortening the war.
1945
Von Neumann Architecture — John von Neumann, USA
Published the "stored program" concept: a computer's instructions AND data should both be stored in the same memory. This architecture (CPU + Memory + I/O + stored programs) is still the blueprint of virtually every computer built today, 80 years later.
1945
ENIAC — Eckert & Mauchly, USA
Electronic Numerical Integrator and Computer — first general-purpose electronic digital computer. Facts: 17,468 vacuum tubes, 70,000 resistors, 30 tons, filled an 1,800 sq ft room, consumed 150 kilowatts. Used to calculate artillery firing tables and hydrogen bomb calculations.
1951
UNIVAC I — Remington Rand, USA
First commercial computer sold in the United States. Used for the 1950 US Census. Made famous when CBS used it to correctly predict Eisenhower's 1952 presidential election victory — the first computer prediction broadcast on television.

The Five Generations of Computers

Computer generations are defined by the key electronic component used. Each generation brought dramatic improvements in size, speed, cost, and capability.

1946 – 1958
1st Generation — Vacuum Tubes

Technology: Thermionic vacuum tubes as electronic switches
Language: Machine language only (binary 0s and 1s)
Input/Output: Punched cards, paper tape
Storage: Magnetic drums
Size: Room-sized (ENIAC = 1,800 sq ft)
Speed: Milliseconds per calculation
Problems: Extreme heat, constant tube failures, massive power consumption
Key Machines: ENIAC (1945), UNIVAC I (1951), IBM 701 (1952)

1959 – 1964
2nd Generation — Transistors

Technology: Transistors (invented Bell Labs 1947 by Shockley, Bardeen, Brattain)
Language: Assembly language; early COBOL and FORTRAN
Input/Output: Magnetic tape, punch cards
Storage: Magnetic core memory
Size: Much smaller; cabinet-sized
Speed: Microseconds
Advantages: Faster, smaller, cheaper, more reliable, far less heat
Key Machines: IBM 1401, IBM 7094, CDC 1604

1965 – 1970
3rd Generation — Integrated Circuits

Technology: ICs — multiple transistors on one silicon chip (Jack Kilby, Texas Instruments, 1958)
Language: High-level languages dominant: BASIC, COBOL, PL/I
I/O: Keyboards and monitors introduced (goodbye punch cards)
Storage: Magnetic disks (HDDs)
Size: Minicomputers introduced — desk-sized
Speed: Nanoseconds
Key Machines: IBM System/360, PDP-8 (first minicomputer)

1971 – Present
4th Generation — Microprocessors

Technology: Very Large Scale Integration (VLSI) — entire CPU on ONE chip
First: Intel 4004 (1971) — 4-bit, 2,300 transistors on one chip
Language: All high-level; GUIs introduced
Key: Apple II (1977), IBM PC (1981), Windows, Internet, smartphones
Speed: Picoseconds; 3–5+ GHz modern CPUs with billions of transistors
Impact: Personal computing revolution; everyone has a computer in their pocket

Present – Future
5th Generation — Artificial Intelligence & Quantum Computing

Technology: AI chips (NPUs/TPUs), quantum processors, neuromorphic computing, natural language processing
Key Development: IBM Watson (2011), AlphaGo (2016), ChatGPT/GPT-4 (2022–2023), Google Sycamore quantum supremacy (2019), NVIDIA AI GPUs
Quantum Computing: Uses quantum bits (qubits) that can represent 0, 1, or BOTH simultaneously (superposition). Exponentially faster for specific problems: cryptography, drug discovery, optimization.
AI Focus: Machine learning, neural networks, computer vision, voice recognition. The computer "learns" rather than being explicitly programmed.
Philippine relevance: Mid-range chipsets like the Dimensity 8350, common in phones sold locally, include a dedicated APU (AI Processing Unit) for real-time AI tasks — this is 5th Generation computing in your pocket.

🧠
Memory Trick: 5 Generations

V-T-I-M-A — Vacuum tubes → Transistors → Integrated Circuits → Microprocessors → Artificial Intelligence. Each solved the previous generation's biggest problem: heat, size, cost, access, and intelligence.

CHAPTER 03
Computer Hardware

Hardware refers to all physical components you can touch. Every computer — from ENIAC to a modern smartphone — follows the same fundamental architecture: a processor, memory, storage, and input/output devices connected by buses. This chapter breaks each component down in detail.

⚙️
The Computer System = Hardware + Software + Peopleware

A "computer system" is more than the machine itself — it's a complete, working setup. It has three parts: Hardware (physical, touchable components — this whole chapter), Software (the instructions that tell hardware what to do — see Chapter 07), and Peopleware (the human role — the people who operate, program, and maintain the system, covered at the end of this chapter). Remove any one part and the "system" stops functioning.

🏗️
Von Neumann Architecture — The Blueprint of All Computers

All modern computers follow this structure: CPU ↔ connected via a Bus ↔ Memory (RAM) ↔ Storage (SSD/HDD) ↔ I/O Devices. Instructions AND data both live in the same memory. The CPU fetches instructions, decodes them, and executes them in a continuous loop called the Fetch-Decode-Execute cycle.

CPU — Central Processing Unit

The CPU is the "brain" of the computer. It performs all logical and arithmetic operations and controls all other hardware. Everything the computer does passes through the CPU.

ComponentFull NameWhat It Does
CUControl UnitDirects all CPU operations. Fetches instructions from memory, decodes them, and tells the ALU and registers what to do. The "manager" or "conductor" of the CPU — it does no actual calculation itself.
ALUArithmetic Logic UnitPerforms ALL arithmetic (addition, subtraction, multiplication, division) and ALL logical operations (AND, OR, NOT, XOR, comparisons like >, <, ==). The "calculator" of the CPU.
RegistersProcessor RegistersUltra-fast, tiny storage locations INSIDE the CPU core itself. Hold data currently being processed. Much faster than RAM. Examples: Program Counter (PC) tracks next instruction address; Accumulator stores results; Instruction Register holds current instruction.
CacheCPU Cache MemorySmall but very fast memory between CPU and RAM. Stores frequently used data to avoid slow RAM access. L1 (fastest, smallest, inside each core ~32–512KB), L2 (medium), L3 (largest, shared between cores, 4–64MB).
ClockSystem ClockGenerates synchronized pulses that time all CPU operations. Measured in GHz (gigahertz = billions of pulses/second). Modern CPUs: 3–5.5 GHz. More GHz generally = faster processing, but architecture matters more now.
CoresProcessing CoresEach core is an independent processing unit. Dual-core = 2 CPUs in one chip. Modern phones have 8 cores (octa-core). A Dimensity 8350-class chipset, for example, has 8 cores across 3 performance clusters (1+3+4 big.MIDDLE.LITTLE architecture).

Fetch-Decode-Execute Cycle

This is the fundamental loop the CPU runs billions of times per second:

1
FETCH
Control Unit reads the next instruction from RAM. The Program Counter register holds the memory address of the next instruction. After fetching, the PC increments to point to the next instruction.
2
DECODE
Control Unit decodes the instruction — translates machine code into control signals that tell the ALU and registers exactly what to do (add? compare? move data?).
3
EXECUTE
The ALU or other unit performs the operation. Result is stored back in a register or written to memory. Then the cycle repeats — billions of times per second.

The Motherboard — Where Everything Connects

The motherboard holds together every component covered above — CPU, memory, storage, and I/O — through a set of standardized sockets, slots, and connectors. Understanding these ties the whole chapter together: the CPU sits in the socket, RAM sits in the memory slots, storage plugs into IDE/SATA, and expansion cards plug into PCI/AGP.

ComponentWhat It Does
SocketThe connection point that allows a CPU to be physically attached to the motherboard (e.g. older Socket 370/PGA370, modern LGA sockets). The socket type must match the CPU generation.
ATX Power ConnectorThe connector(s) inside the case that feed power from the PSU (power supply unit) to an ATX-style motherboard — commonly a 24-pin main connector plus a separate 4-pin CPU power connector.
Memory Slot (RAM Slot)Lets RAM modules be inserted into the motherboard. Most boards have 2–4 slots; the slot type determines which RAM generation (DDR3/DDR4/DDR5) is compatible.
DIMMDual In-line Memory Module — the circuit board that physically holds the memory chips and plugs into a memory slot. A 64-bit data path lets DIMMs be installed one at a time, unlike older SIMMs which had to be added in pairs.
IDE / ATAIntegrated Drive Electronics (also called Advanced Technology Attachment) — an older standard interface connecting the motherboard to storage drives (HDDs, CD/DVD drives) via a ribbon cable, superseded on modern boards by SATA.
NorthbridgeAn integrated circuit that handles high-speed communication between the CPU, RAM, and the graphics interface (AGP/PCIe). Directly connected to the CPU — the "closer, faster" chipset.
SouthbridgeAn integrated circuit responsible for slower I/O: hard drive controller, USB, PCI, legacy IDE, BIOS, and Ethernet. Communicates with the CPU through the Northbridge.
PCI SlotPeripheral Component Interconnect — a general-purpose expansion slot for adding cards like graphics cards, modems, or extra USB ports.
AGP SlotAccelerated Graphics Port — an older dedicated point-to-point slot built specifically for video cards and 3D accelerators, giving the graphics controller direct access to system memory. Mostly replaced by PCI Express (PCIe) on modern boards.

CHAPTER 04
Number Systems & Conversions

This is the most exam-heavy topic in CC 101. Number systems are ways to represent numbers using different bases. Computers use binary internally, programmers use hexadecimal as shorthand, and humans use decimal. Master all conversions between the four systems.

⚠️
Exam Alert

Conversion problems — especially decimal ↔ binary and binary ↔ hexadecimal — appear on virtually every CC 101 midterm and final. Do NOT just memorize the steps; understand the pattern so you can solve any number, not just the examples you studied.

Why Do Computers Use Binary?

A transistor is a switch — it is either ON (conducting electricity) or OFF (blocking it). These two states map perfectly to 1 and 0. Every computation reduces to billions of these ON/OFF decisions happening billions of times per second. Binary is the only number system a physical transistor can naturally represent.

Conversion Methods — Full Step-by-Step Examples

1. Binary → Decimal (Positional Value Method)

Each binary digit is multiplied by 2 raised to the power of its position (counting right-to-left starting at 0), then all products are summed.

Example: 1011₂ → Decimal
Positions (right to left):  3  2  1  0
Digits:                      1  0  1  1

1 × 2³ = 1 × 8 =  8
0 × 2² = 0 × 4 =  0
1 × 2¹ = 1 × 2 =  2
1 × 2⁰ = 1 × 1 =  1

Sum: 8 + 0 + 2 + 1 = 11

∴ 1011₂ = 11₁₀  ✓
Example 2: 11010110₂ → Decimal
Positions:  7    6    5    4    3    2    1    0
Digits:     1    1    0    1    0    1    1    0

1×128 = 128
1×64  =  64
0×32  =   0
1×16  =  16
0×8   =   0
1×4   =   4
1×2   =   2
0×1   =   0

Sum: 128+64+0+16+0+4+2+0 = 214

∴ 11010110₂ = 214₁₀  ✓

2. Decimal → Binary (Repeated Division by 2)

Divide the number by 2 repeatedly, recording remainders. Read remainders BOTTOM to TOP for the binary result.

Example: 25₁₀ → Binary
25 ÷ 2 = 12  remainder  1  ← LSB (Least Significant Bit, rightmost)
12 ÷ 2 =  6  remainder  0
 6 ÷ 2 =  3  remainder  0
 3 ÷ 2 =  1  remainder  1
 1 ÷ 2 =  0  remainder  1  ← MSB (Most Significant Bit, leftmost)

Read remainders BOTTOM to TOP: 1, 1, 0, 0, 1

∴ 25₁₀ = 11001₂

Verify: 16 + 8 + 0 + 0 + 1 = 25 ✓
Example 2: 156₁₀ → Binary
156 ÷ 2 = 78  R 0
 78 ÷ 2 = 39  R 0
 39 ÷ 2 = 19  R 1
 19 ÷ 2 =  9  R 1
  9 ÷ 2 =  4  R 1
  4 ÷ 2 =  2  R 0
  2 ÷ 2 =  1  R 0
  1 ÷ 2 =  0  R 1

Bottom to top: 10011100

∴ 156₁₀ = 10011100₂

Verify: 128+0+0+16+8+4+0+0 = 156 ✓

Alternate Method: Powers of Two (Subtraction Approach)

Instead of dividing, you can build the binary number by repeatedly subtracting the largest power of 2 that still fits. Useful when you have the powers-of-2 sequence memorized: …256, 128, 64, 32, 16, 8, 4, 2, 1.

Example: 300₁₀ → Binary (Powers of Two)
256 fits into 300 → write 1, remainder 300-256 = 44
128 does NOT fit into 44 → write 0
 64 does NOT fit into 44 → write 0
 32 fits into 44 → write 1, remainder 44-32 = 12
 16 does NOT fit into 12 → write 0
  8 fits into 12 → write 1, remainder 12-8 = 4
  4 fits into 4  → write 1, remainder 4-4 = 0
  2 does NOT fit into 0 → write 0
  1 does NOT fit into 0 → write 0

  256 128 64 32 16  8  4  2  1
   1   0   0  1  0  1  1  0  0

∴ 300₁₀ = 100101100₂

Verify: 256+32+8+4 = 300 ✓
💡
Division vs. Powers of Two

Both methods always give the same answer — use whichever is faster for you. Division-by-2 is more mechanical (good for large or awkward numbers); Powers of Two is faster once you have the sequence 1, 2, 4, 8, 16, 32, 64, 128, 256… memorized.

3. Binary → Hexadecimal (Group into 4s)

Group binary digits into sets of 4 from the right. Pad with leading zeros if needed. Convert each group to its hex digit.

Example: 10110111₂ → Hex
Group into 4s from right:
  1011  |  0111

Convert each group using the chart:
  1011 = 8+2+1 = 11 = B
  0111 = 4+2+1 =  7 = 7

∴ 10110111₂ = B7₁₆
Example 2: 1111001011₂ → Hex (pad left with 0s)
Pad to groups of 4: 0011 | 1100 | 1011

Convert:
  0011 = 2+1         = 3
  1100 = 8+4         = 12 = C
  1011 = 8+2+1       = 11 = B

∴ 1111001011₂ = 3CB₁₆

4. Hexadecimal → Binary (Each hex digit = 4 binary digits)

Example: 4F3₁₆ → Binary
4 → 0100
F → 1111   (F = 15)
3 → 0011

∴ 4F3₁₆ = 010011110011₂

5. Decimal → Hexadecimal (Repeated Division by 16)

Same as decimal-to-binary but divide by 16. If remainder ≥ 10, convert to A–F.

Example: 255₁₀ → Hex
255 ÷ 16 = 15  remainder 15 = F
 15 ÷ 16 =  0  remainder 15 = F

Read bottom to top: F, F

∴ 255₁₀ = FF₁₆

This is why pure white in web colors is #FFFFFF
(R=255, G=255, B=255 → FF FF FF)
Example 2: 3072₁₀ → Hex
3072 ÷ 16 = 192  R  0
 192 ÷ 16 =  12  R  0
  12 ÷ 16 =   0  R 12 = C

Read bottom to top: C, 0, 0

∴ 3072₁₀ = C00₁₆

Example: 101011₂ → Octal
Group into 3s from right:
  101 | 011

Convert:

  011 = 2+1 = 3

∴ 101011₂ = 53₈

Verify: 5×8 + 3 = 43₁₀
Binary: 32+8+2+1 = 43₁₀ ✓

Example: 257₈ → Binary
2 → 010
5 → 101

∴ 257₈ = 010101111₂

8. Decimal → Octal (Repeated Division by 8)

Example: 128₁₀ → Octal
128 ÷ 8 = 16  remainder 0
 16 ÷ 8 =  2  remainder 0
  2 ÷ 8 =  0  remainder 2

Read bottom to top: 2, 0, 0

∴ 128₁₀ = 200₈
Example 2: 287₁₀ → Octal
287 ÷ 8 = 35  remainder 7

  4 ÷ 8 =  0  remainder 4

Read bottom to top: 4, 3, 7

∴ 287₁₀ = 437₈

9. Octal → Decimal (Positional Value Method)

Example: 176₈ → Decimal
6 × 8⁰ = 6 × 1  =  6
7 × 8¹ = 7 × 8  = 56
1 × 8² = 1 × 64 = 64

Sum: 6 + 56 + 64 = 126

∴ 176₈ = 126₁₀

10. Octal → Hexadecimal (Convert via Binary)

There's no direct shortcut — convert octal to binary first, then regroup the binary into 4-bit chunks for hex.

Example: 176₈ → Hexadecimal
Step 1: Each octal digit → 3-bit binary
  1 → 001   7 → 111   6 → 110
  Binary: 001111110

Step 2: Regroup into 4-bit chunks from the right
  0001 1111 0 → pad → 0000 1111 10 → correctly grouped: 0111 1110
  (equivalently: 176₈ = 126₁₀ = 7E₁₆, verified against Step 9 above)

∴ 176₈ = 7E₁₆

11. Hexadecimal → Octal (Convert via Binary)

Example: 176₁₆ → Octal
Step 1: Each hex digit → 4-bit binary
  1 → 0001   7 → 0111   6 → 0110
  Binary: 000101110110

Step 2: Regroup into 3-bit chunks from the right
  000 101 110 110 → drop leading zeros → 101 110 110
  101 = 5   110 = 6   110 = 6

∴ 176₁₆ = 566₈
🔑
Key Insight — Octal/Hex Never Convert Directly

Octal (base 8 = 2³) and Hexadecimal (base 16 = 2⁴) both "line up" cleanly with binary because 8 and 16 are powers of 2 — but not with each other. Always use binary as the bridge when converting between octal and hexadecimal.

Fractional (Radix Point) Conversions

Every number system has a "point" separating the whole part from the fractional part — decimal point, binary point, hexadecimal point. Digits to the right of the point use negative exponents (2⁻¹, 2⁻², 2⁻³…).

Binary → Decimal (With Fraction)

Example: 1011.11₂ → Decimal
1×2³ + 0×2² + 1×2¹ + 1×2⁰ + 1×2⁻¹ + 1×2⁻²
=  8  +  0  +  2   +  1   +  0.5  +  0.25

Sum: 8 + 0 + 2 + 1 + 0.5 + 0.25 = 11.75

∴ 1011.11₂ = 11.75₁₀

Decimal → Binary (With Fraction) — Successive Multiplication

Multiply the fractional part by the target base. The integer part of each product becomes the next digit; carry the remaining fractional part forward. Stop when the fraction hits 0 or you have enough digits.

Example: 0.375₁₀ → Binary
0.375 × 2 = 0.75  → integer part 0, carry 0.75
0.75  × 2 = 1.5   → integer part 1, carry 0.5
0.5   × 2 = 1.0   → integer part 1, carry 0.0 (done — fraction is 0)

Read integer parts TOP to BOTTOM: 0, 1, 1

∴ 0.375₁₀ = 0.011₂

Verify: 0×2⁻¹ + 1×2⁻² + 1×2⁻³ = 0 + 0.25 + 0.125 = 0.375 ✓

Octal → Hexadecimal (With Fraction, via Binary)

Example: 635.27₈ → Hexadecimal
Step 1: Each octal digit → 3-bit binary (both sides of the point)
  6=110  3=011  5=101  .  2=010  7=111
  Binary: 110 011 101 . 010 111

Step 2: Regroup into 4-bit chunks — from the point outward in
         BOTH directions (left for the whole part, right for
         the fraction, padding with 0s at each far end)
  0001 1001 1101 . 0101 1100
  1    9    D    .  5    C

∴ 635.27₈ = 19D.5C₁₆
⚠️
Padding Direction Matters

When regrouping bits around a radix point, pad the whole-number part on the left (most significant end) and the fractional part on the right (least significant end) — never the opposite, or the value changes.

Why 0 − 1 = 1?

Just like decimal subtraction, when the top digit is smaller you borrow from the next column to the left. In binary, borrowing 1 adds "2" to the current column (0 becomes 10₂ = 2, then 2−1=1) — that's why the digit result is 1 with a borrow flag set.

Every piece of data inside a computer — text, images, audio, video — is ultimately stored as binary numbers (0s and 1s). Data representation is the study of how different types of information are encoded into binary and decoded back again.

ASCII — Text Encoding

ASCII (American Standard Code for Information Interchange) was developed in 1963, primarily by Bob Bemer at IBM. It is a 7-bit encoding standard that maps 128 characters — letters, digits, punctuation, and control characters — to numbers 0–127.

Why it matters: When you type "A" on your keyboard, the computer stores the number 65 (01000001 in binary). ASCII is the translation table between human characters and computer storage.

RangeCharactersKey Values to Know
0–31Control characters (non-printable)0 = Null (NUL), 8 = Backspace, 9 = Tab, 10 = Line Feed (newline), 13 = Carriage Return, 27 = Escape

48–57Digits '0' through '9''0' = 48, '1' = 49, ..., '9' = 57. NOTE: The character '0' is NOT the same as the number 0!

💡
Key Pattern: Uppercase to Lowercase = +32

'A' = 65. 'a' = 97. Difference = 32. This is how case-conversion works in code. To convert uppercase to lowercase: add 32. To convert lowercase to uppercase: subtract 32. This works for ALL 26 letters of the alphabet.

Unicode — Universal Text Encoding

ASCII only covers 128 characters — it cannot represent Filipino characters (ñ, Á), Chinese, Arabic, emoji, or most of the world's writing systems. Unicode was created in 1991 by the Unicode Consortium to solve this permanently.

How Images Are Stored

1
Pixel Grid
A digital image is a grid of pixels (picture elements). A 1920×1080 display has 1,920 × 1,080 = 2,073,600 pixels. A high-refresh phone display at 2720×1224 resolution has approximately 3.33 million pixels.
2
RGB Color Model
Each pixel stores 3 color channels: Red, Green, Blue. Each channel ranges from 0–255 (8 bits). Combined: 24-bit "True Color" = 16.7 million possible colors. Pure red = R:255, G:0, B:0 stored as 11111111 00000000 00000000 in binary.
3
Color Depth
8-bit = 256 colors. 16-bit = 65,536 colors. 24-bit True Color = 16.7 million colors. 32-bit = 24-bit + 8-bit alpha (transparency channel). Modern AMOLED displays support 10-bit HDR for ~1 billion colors.
4
Image File Formats
BMP — uncompressed, huge files. JPEG/JPG — lossy compression, ideal for photos. PNG — lossless compression, supports transparency, ideal for graphics/logos. GIF — 256 colors, animation support. WebP — modern Google format, better compression than JPEG/PNG. HEIC — Apple's efficient format for iPhones.

Operating Systems

An Operating System (OS) is the master software layer that manages all hardware resources and provides a platform for application software to run. Without an OS, application software cannot function. It is the bridge between the user, software, and hardware.

🇵🇭
Filipino Analogy — The Operating System

Think of the OS as the Barangay Captain. It manages all community resources (hardware), lets residents (applications) use shared facilities (CPU, memory, printer), settles conflicts when two residents want the same resource at the same time (process scheduling), maintains records (file system), and enforces rules (security/permissions). Without a Barangay Captain, everyone fights over resources and nothing works in order.

The Booting Process

Boot = the complete sequence of events from pressing the power button to seeing the login screen.

1
Power ON
Electrical power flows to all components. Capacitors stabilize voltage. CPU begins execution from a fixed, hardwired address in ROM where the BIOS/UEFI firmware lives.
2
POST — Power-On Self-Test
BIOS/UEFI performs hardware health checks: RAM quantity and functionality, CPU, keyboard presence, storage devices, GPU. If something critical fails: beep codes (one beep usually = success). This is why PCs sometimes beep on startup.
3
BIOS / UEFI Initializes
BIOS (Basic Input/Output System) is older firmware, 16-bit, max 2.2 TB drives. UEFI (Unified Extensible Firmware Interface) is modern: 32/64-bit, supports drives >2.2 TB, faster boot (no 1-minute BIOS logo screens), Secure Boot. Both live in a Flash ROM chip on the motherboard.
4
Boot Device Found
BIOS/UEFI checks the boot order list (SSD first, then USB, then network...) and finds the bootable device. Reads the MBR (Master Boot Record, legacy) or ESP (EFI System Partition, UEFI) to locate the OS bootloader.
5
Bootloader Runs

Computer Security & Ethics

Types of Malware

Malware (malicious software) is any software intentionally designed to cause damage, steal data, or gain unauthorized access.

Virus
Attaches itself to a legitimate file or program. Requires a host file and human action (opening the infected file) to activate and spread. Can corrupt or delete data.
Worm
Self-replicating malware that spreads automatically across networks WITHOUT needing a host file or human action — exploits network vulnerabilities directly. Can spread far faster than viruses.
Trojan Horse
Disguises itself as legitimate, useful software to trick users into installing it. Named after the Greek mythological story. Once installed, it can open backdoors for attackers.
Ransomware
Encrypts the victim's files, making them inaccessible, then demands payment (usually cryptocurrency) for the decryption key. Major real-world example: WannaCry (2017) affected 200,000+ computers across 150 countries.
Spyware
Secretly monitors user activity — keystrokes, browsing habits, screen content — and sends data to an attacker without consent.
Adware
Automatically displays unwanted advertisements, often bundled with free software. Less destructive than other malware but invasive and can slow systems significantly.
Rootkit
Designed to hide deep within the OS, granting an attacker persistent privileged (admin/root) access while remaining undetected by normal antivirus scans.
Keylogger
Records every keystroke typed by the user, capturing passwords, messages, and sensitive data — often a component within spyware or trojans.
Privilege Escalation
A technique where an attacker gains access rights beyond what was originally granted, often by exploiting a bug or misconfiguration, to reach admin/root-level control.
Botnet
A network of malware-infected computers ("bots") remotely controlled by an attacker, commonly used to launch large-scale attacks such as DDoS or to send spam.
Logic Bomb
Malicious code deliberately inserted into software that stays dormant until triggered by a specific condition or date, at which point it executes its damaging payload.
Spam
Unsolicited, often bulk-sent messages — more of a nuisance than direct malware on its own, but a common delivery vector for phishing links and other malware.

Vulnerability

A vulnerability is a weakness in a security system. Weaknesses can appear in any element of a computer — hardware, operating system, or software — and each asset type (hardware, software, data) has its own characteristic vulnerabilities.

Four Classes of Security Threats

Any threat to a computer system falls into one of four categories, based on how it disrupts the normal flow of information from a source to a destination:

UNAUTHORIZED ACCESS
Interception
An unauthorized party gains access to an asset — e.g. eavesdropping on data in transit, or theft of hardware/software.
ASSET LOST/UNUSABLE
Interruption
An asset of the system becomes lost, unavailable, or unusable — e.g. a Denial of Service attack, or deletion of a file.
ACCESS + TAMPERING
Modification
An unauthorized party not only accesses but tampers with an asset — e.g. injecting malicious code into software.
COUNTERFEIT OBJECTS
Fabrication
An unauthorized party creates counterfeit objects on a computing system — e.g. inserting fake records into a database.

Physically Securing Your Computer

Software defenses matter little if the hardware itself isn't protected.

  • Computer locks — cable locks that physically secure a desktop or laptop to a desk, deterring opportunistic theft.
  • Mobile proximity alarms — a paired transmitter/receiver that triggers an alarm if a device is moved beyond a set range from its owner.
  • Choose your browser deliberately — most malware arrives through the web browser, so its security track record matters.
  • Download only from trusted sources — applies to all software, including antivirus programs themselves; a fake "antivirus" download is a classic malware delivery method.

What Is Graphic Design?

Graphic design is the art and profession of selecting and arranging visual elements — typography, images, symbols, and colors — to convey a message to an audience. Graphic designers plan, analyze, and create visual solutions to communication problems, deciding the most effective way to get a message across in print, electronic, or film media.

🎨
What Graphic Designers Produce

Magazines, newspapers, and journals · Corporate reports and publications · Promotional displays and packaging · Commercial displays and billboards · Brochures · Company logos and signs · Webpages and multimedia projects.

The 7 Basic Principles of Graphic Design

Every well-designed layout — a poster, a slide, a resume — applies some combination of these seven principles.

1. Balance
Distributing design elements (shapes, text boxes, images) evenly throughout the layout. Three types: Symmetrical (mirrored), Asymmetrical (uneven but visually weighted), Radial (arranged around a center point).
2. Alignment
Creates a visual connection between elements — images, shapes, or blocks of text — by lining them up along shared edges rather than scattering them randomly.
3. Hierarchy
Combines dominance and priority, giving extra visual weight to certain elements (bigger headline, bolder color) so the eye knows what to look at first.
4. Contrast
Guides the viewer's attention to key elements by making them visually distinct — e.g. light text on a dark background reads clearly; low-contrast text gets lost.
5. Rhythm
Brings together different elements in a repeated, consistent pattern to create a more organized, cohesive look — irregular, inconsistent spacing feels chaotic.
6. Proximity
Declutters a design by grouping related elements close together, forming a visual connection between items that belong together (vs. scattering them apart).
7. Colour & Space
The right color palette defines the design's tone. Space is the area around or between elements — enough of it (whitespace) keeps a layout from feeling cramped.

Typography

Typography is the art of arranging letters and text so the copy is legible, clear, and visually appealing. It dates back to the 11th century innovation of movable type, and before the digital age was a specialized craft tied to books, magazines, and public works.

🔤
Why Typography Matters

Typography is far more than picking a pretty font — it's a vital part of user interface and visual design. It builds brand recognition (a consistent typeface makes a brand instantly identifiable), influences decision-making (tone shapes how a message is received), and holds the reader's attention.

Choosing the Right Typeface

  • Think about personality — does the typeface's shape and weight match the message's mood?
  • Reflect on tone — formal, playful, urgent, elegant?
  • Don't skimp on function — legibility at the intended size always comes before style.
  • Consider performance — will it render consistently across devices/platforms?
  • Get inspired — reference existing well-designed work for direction.
  • Take time to test — view the typeface at actual size and context before finalizing.

Digital Logic Circuits & Binary Logic

Digital logic circuits are used to process information inside computers. They operate on binary variables that are symbolically represented by the values 0 and 1 — also described as low and high logic. Binary logic deals with these binary variables and the logic operations applied to them: ON = Logic 1, OFF = Logic 0.

🇵🇭
The Transistor — The Physical Switch Behind It All

A transistor is a special kind of electronic device used for many important functions. In computers, it serves as a switch that is either ON or OFF — the same ON/OFF idea from Chapter 04's binary discussion, just now realized as an actual physical component instead of a written digit.

Logic Gates & Boolean Algebra

Logic gates are the actual physical components that perform arithmetic operations or make choices in a computer — constructed from a number of primitive electronic elements (transistors). A logic gate takes one or more binary inputs (operands) and produces a single binary output, e.g. A + B = C where A and B are operands, "+" is the operator, and C is the output.

Boolean Algebra is an expression or statement whose purpose is to solve logic problems — it is ideally suited to digital circuit analysis. A Truth Table is a table of all possible combinations of input variables, showing the relationship between those input values and the resulting output that describes the behavior of a logic gate (Mano, 2001).

The Internet

The Internet is a globally connected network system that uses TCP/IP to transmit data across many kinds of media. It's a network of global exchanges — private, public, business, academic, and government networks — linked by guided (wired), wireless, and fiber-optic technologies.

Internet Protocol (IP) is the Internet's primary component and communications backbone. Because the Internet is built from both hardware and software layers, IP is the addressing standard used to identify every uniquely connected device. The two versions in active use are IPv4 and IPv6.

The World Wide Web

The World Wide Web (WWW) is a network of online content formatted in HTML and accessed via HTTP — all the interlinked HTML pages reachable over the Internet. It's what most people mean when they casually say "the Internet," but the two aren't the same thing: the Internet is the underlying network connection; the Web is the collection of pages, pictures, videos, and content you reach through a browser using that connection. The early Web was entirely text-based, hosted only by organizations technically capable of running a Web server and writing HTML.

🧭

This chapter's official slide says the Web was "originally designed in 1991 by Tim Berners-Lee." Chapter 08 of this guide says "invented in 1989."
